# Download users

You can download a list of users in your organization in XLSX or JSON format for offline analysis, reporting, or integration with external tools.

The downloaded file includes user details such as user ID, first and last name, organization ID, last login date, and other account information.

### Download users

To download a list of users:

1. From the left sidebar, select **User management**.
2. Select **Download**.
3. Select either **XLSX spreadsheet** or **JSON file** to start the download.
