# Download resources

You can download a complete list of discovered cloud resources for analysis, reports, or integration with external tools.

The downloaded file includes metadata such as resource type, cost, usage, tags, ownership, and more.

### Download resources

To download a list of resources:

1. From the left sidebar, select **Resources**.
2. (Optional) Select a data range and apply filters as needed.
3. Select **Download**. The **Download** option is located above the cloud resources table. You may need to scroll down to see it.
4. Select **XLSX spreadsheet** or **JSON file** to start the download.

If the data is too large, a warning message is displayed. Refine your filters to reduce the amount of data, and then try the download again.
